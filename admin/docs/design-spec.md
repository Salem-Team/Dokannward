# UI/UX Design Specification  

UI/UX Design Prompt for AI Agent:

Project: Korfdya - Premium Bag E-commerce Platform
Languages: English & Arabic (RTL support required)

Design Vision:
"Create a luxury, tactile shopping experience that makes customers feel they're handling premium bags physically through the screen."

Core Design Principles:

Luxury Minimalism

Clean, spacious layouts with premium whitespace

Sophisticated color palette: deep navies, warm taupes, accent golds

Premium typography: elegant serif for headings, clean sans for body

Subtle animations and micro-interactions

Bag-First Visual Hierarchy

Products are the heroes - large, high-quality imagery

Multiple angles and zoom functionality as standard

Video integration for bag demonstrations

"See the details" focused user journey

Cultural Intelligence

Seamless RTL/LTR switching without design compromise

Culturally appropriate imagery and color meanings

Arabic typography that maintains luxury feel

Localized shopping patterns and payment preferences

Key Pages & Components:

1. Product Gallery & Display:

"360-degree view" simulation with smooth transitions

"Detail zoom" for material texture and craftsmanship

"Size comparison" visualization against common objects

"What fits inside" interactive feature

2. Navigation & Filters:

Intuitive category system for bag types (work, travel, casual, luxury)

Smart filters: material type, size range, water resistance, compartments

Visual filter system using bag attributes as icons

Persistent filter sidebar that doesn't disrupt browsing

3. Shopping Experience:

Add to Cart: Elegant animation showing bag moving to cart

Checkout Process: Minimal steps, maximum clarity

Arabic Form Fields: Proper RTL form validation and input handling

Payment Flow: Localized payment method prominence (Mada first for Saudi)

4. Mobile-First Responsive Design:

Thumb-friendly navigation on mobile

Swipe-friendly image galleries

Optimized touch targets for all interactive elements

Progressive loading for bag imagery

Color Palette:

Primary: Deep Navy (#1E2A38) - trust & sophistication

Secondary: Warm Taupe (#C4B7A6) - tactile & premium

Accent: Gold (#D4AF37) - luxury & quality

Neutral: Soft Gray (#F5F5F5) - clean backgrounds

Text: Charcoal (#2D3748) - optimal readability

Typography:

English: Playfair Display (headings), Inter (body)

Arabic: Noto Naskh Arabic (elegant, highly readable)

Weights: Regular, Medium, SemiBold for hierarchy

Interactive Elements & Micro-interactions:

Hover States: Subtle scale transforms on product cards

Loading: Elegant skeleton screens for images

Add to Cart: Bag icon "fills" with animation

Filtering: Smooth transition as results update

Image Zoom: Natural, gesture-based zoom interface

Accessibility Requirements:

WCAG 2.1 AA compliance

High contrast ratios for text

Keyboard navigation support

Screen reader optimized for both languages

Color-blind friendly palette

Mood Board Keywords:

Luxury retail, tactile materials, unboxing experience

High-fashion photography, clean product staging

Arabic calligraphy elegance, modern Middle Eastern design

Seamless digital experience, intuitive navigation

Reference Inspirations:

Premium fashion e-commerce (Net-a-Porter, Mr Porter)

Luxury bag brand sites (Coach, Tumi, Longchamp)

Modern Arabic digital design patterns

Apple-level interface polish and simplicity

Deliverables Expected:

Complete UI kit with RTL/LTR components

Interactive prototype demonstrating key user flows

Design system documentation for both languages

Mobile and desktop mockups for all critical pages

Animation specifications and transition guidelines

Priority: Start with product listing and detail pages, then expand to checkout and user accounts. Ensure RTL consideration is baked into every component from day one.
